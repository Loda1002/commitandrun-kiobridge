# 접근성 및 심사 요건 실측 체크리스트 (A11Y_CHECK.md)

| 항목                          | 어떻게 재나                                             | 실측값                                                  | 판정 |

| **페이지 언어**               | 브라우저 개발자도구에서 `<html>` 태그의 `lang`              | `ko`                                                | PASS |
| **페이지 제목**               | 브라우저 탭에 뜨는 글자 (`<title>`)                        | `KioBridge — 배리어프리 키오스크 도우미`                | PASS |
| **글씨 1배 / 1.25배 / 1.5배**  | 제목 글자 실제 픽셀 (Computed → font-size, `2.5rem` 기준) | `40px` / `50px` / `60px`                              | PASS |
| **버튼 최소 높이**             | 가장 작은 버튼의 실제 픽셀 (`var(--tap-min)` 이상)          | `44px` (메인 버튼은 60px)                               |PASS(≥ 44px)|
| **1.5배에서 가로 스크롤**      | 글씨 1.5배 확대 시 가로 스크롤 발생 여부                     | `없음`                                              | PASS |
| **고대비 켰을 때 배경 / 글자**  | 고대비 토글 시 실제 적용 색상 값 (CSS 변수)                  | 배경: `#000000` / 글자: `#ffffff`                     | PASS |
| **키보드로 전 화면 일주**     | Tab, Shift+Tab, Enter, Space 조작 시 막히는 곳            | `없음`                                                | PASS |
| **라벨 없는 입력칸**          | `<label htmlFor=...>` 또는 `<legend>` 누락된 인풋 개수    | `0개`                                                  | PASS |
| **색깔만으로 구분하는 곳**        | 아이콘/텍스트 없이 색상으로만 상태를 전달하는 곳           | `0개`                                                 | PASS |
| **고르는 질문 중 "모르겠어요" 없는 것** | 단일/다중 선택 질문 중 "모르겠어요" 누락 개수 (개수·예산 제외) | `0개`                                         | PASS |
